## 6. Radiometric Calibration Findings — Inspect, Do Not Convert

The audit verified how radiometric calibration is structured internally in INSAT-3DS L1B files.

### 6.1 Calibration Mechanisms Present in the File
ISRO embeds **two parallel calibration mechanisms** in each file:

1. **Pre-computed Lookup Tables (LUTs)**:
   - For every infrared channel, a 1024-element lookup table maps digital counts $C \in [0, 1023]$ directly to physical quantities:
     - Temperature LUT: `IMG_TIR1_TEMP` (units: `K`, Kelvin, shape: `(1024,)`, float32).
     - Radiance LUT: `IMG_TIR1_RADIANCE` (units: `mW.cm-2.sr-1.micron-1`, shape: `(1024,)`, float32).
     - Albedo LUT: `IMG_VIS_ALBEDO`, `IMG_SWIR_ALBEDO` (units: `%`, shape: `(1024,)`, float32).
   - `GreyCount`: An integer array $[0, 1, 2, \dots, 1023]$ representing the count index.
2. **Polynomial Radiance Attributes**:
   - Each channel carries dataset attributes:
     - `online_radiance_scale_factor`: e.g., $0.00186559$ for TIR1
     - `online_radiance_add_offset`: e.g., $-0.0421615$ for TIR1
     - `online_radiance_quad`: $0.0$ (linear sensor response)
     - `online_radiance_scale_factor_gsics`: $0.00192150$ (GSICS inter-calibrated)
     - `online_radiance_add_offset_gsics`: $-0.0535251$ (GSICS inter-calibrated)

### 6.2 The Radiometric Inversion Convention
- Attribute `invert: true` is set on all thermal infrared channels (`IMG_TIR1`, `IMG_TIR2`, `IMG_WV`, `IMG_MIR`).
- **Physical Meaning**:
  - In INSAT raw detector electronics, lower count = higher radiance (hotter).
  - Count $0 \implies 340.0\text{ K}$ (highest brightness temperature).
  - Count $1022 \implies 180.0\text{ K}$ (deep convective cloud tops / coldest temperatures).
  - Count $1023 \implies \text{Fill Value}$ (space background outside the Earth disk).
- **Lookup Table Boundaries**:
  - `IMG_TIR1_TEMP[0]` = $340.0\text{ K}$
  - `IMG_TIR1_TEMP[1022]` = $180.0\text{ K}$
  - `IMG_TIR1_TEMP[1023]` = $180.0\text{ K}$ (with attribute `_FillValue: 999.0`)
  - `IMG_TIR1_RADIANCE[0]` = $1.9122\ \text{mW}\cdot\text{cm}^{-2}\cdot\text{sr}^{-1}\cdot\mu\text{m}^{-1}$
  - `IMG_TIR1_RADIANCE[1023]` = $0.0000\ \text{mW}\cdot\text{cm}^{-2}\cdot\text{sr}^{-1}\cdot\mu\text{m}^{-1}$

### 6.3 Required Documentation / Metadata Before Operational Conversion
Before implementing the conversion step in our preprocessing pipeline:
1. **Decision on Conversion Procedure**: Confirm whether the project will use:
   - **Option A (LUT-based)**: Direct array indexing: $T = \text{LUT}_{\text{TEMP}}[C]$ and $L = \text{LUT}_{\text{RAD}}[C]$. This is exact, pre-computed by ISRO, and avoids running non-linear inverse Planck iterations on millions of pixels.
   - **Option B (GSICS Inter-Calibrated Radiance + Inverse Planck)**: Using the GSICS linear slope and offset: $L_{\text{GSICS}} = C \cdot \text{scale}_{\text{gsics}} + \text{offset}_{\text{gsics}}$, followed by the standard Planck inversion with band-specific central wavelength.
2. **Space Fill Masking**: Space background pixels ($C = 1023$) must be masked prior to computing brightness temperatures, as assigning $180\text{ K}$ to space would distort training gradients.
3. **Target Bounding Box**: Formalize the regional sub-domain (e.g., Indian subcontinent and surrounding oceans: Lat $5^\circ\text{N} - 37^\circ\text{N}$, Lon $65^\circ\text{E} - 97^\circ\text{E}$) before extracting training sequences.
